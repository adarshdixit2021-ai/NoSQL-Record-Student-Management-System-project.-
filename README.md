# NoSQL-Record-Student-Management-System-project.-
Student Record Management System is a database project developed to demonstrate the practical capabilities of NoSQL databases using MongoDB. Designed as part of coursework at Babu Banarasi Das University, the project manages a collection of 50 student records structured with key attributes including roll number, name, age, marks, and city.
